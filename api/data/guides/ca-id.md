California ID After Release

- Gather documents: Release papers, Social Security card (or proof), proof of CA address (shelter letter, lease, or mail).
- If you lack a birth certificate, request a certified copy from your birth state.
- Visit a DMV office; consider making an appointment to reduce wait time.
- Fee assistance may be available through reentry nonprofits and county programs.
- If unhoused, ask about acceptable mailing address options (shelter or trusted contact).
- Ask for a temporary paper ID; the plastic card is mailed within 2–4 weeks.
- If you have fines or holds, staff can explain options — these rarely block getting a basic ID.
- Keep copies of all receipts and forms.
